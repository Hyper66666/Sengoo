CORE
S

LLVM 原生后端

文本 IR → clang 优化链接。不绑 inkwell / llvm-sys，构建链全透明。

S

增量编译

AST 编辑分类。签名不变 → 跳过。100k LOC 增量 33ms，缩减 96%。

A

借用检查

NLL 风格。可变 ⊕ 不可变互斥，编译期拦截，零运行时税。

A

Python 互操作

CPython FFI 层。热路径逐步替换为原生模块，渐进迁移不重写。

A

异步运行时

async def / spawn / select / timeout 一等语法。帧降低 + 原生调度。

B

非侵入反射

--reflect=auto 按需 sidecar 元数据。不用零开销，用时零注册。
