async def fetch_total() -> i64 {
    let task = spawn_task(worker())
    let waited = timeout(task, 500)
    select(waited, sleep(20))
}

    let result = await fetch_total()
    print(result)
    result
}

为什么选择 Sengoo?

写起来轻盈，编译器内部足够硬核。

01

可预测的原生执行

HIR 到 MIR 的降低流程为静态检查、异步帧生成、原生代码生成和定向优化留下了清晰空间。

02

异步路径优先

sleep、timeout、spawn、join、select、任务状态与取消正在由编译器和运行时共同打通。

03

持续扩展的泛型标准库

Option、Result、collections、math、string 与 error 模块拆分清晰，适合直接在源码层组合。

语言速览

清爽语法，严肃编译管线。

Sengoo 希望代码能被快速阅读，同时保留能解释错误、优化原生输出并守住异步边界的编译器架构。 

struct Point {
    x: i64,
    y: i64,
}

impl Point {
    def sum(self) -> i64 {
        self.x + self.y
    }
}
def safe_div(a: i64, b: i64) -> Result<i64, i64> {
    if b == 0 {
        result_err_i64(1)
    } else {
        result_ok_i64(a / b)
    }
}

工具链

围绕编译器生长的一组工具。

sgc

编译器 CLI，覆盖 check、build、run、原生输出与运行时集成。

sgpm

离线包管理器 MVP，支持 manifest、path dependencies、tree 与 clean。

sgfmt

格式化入口，随着语言演进保持源码一致性。

sglsp

语言服务器路径，为编辑器诊断和项目体验打底。

运行时集成

把原生服务包装成 Sengoo 代码能使用的能力。

运行时栈暴露异步调度、网络句柄、数据库调用、Lua 5.4 桥接、protobuf 辅助函数和 FFI wrapper，让源码示例逐步走向真实集成。
