This checkpoint owns the internal typed MIR lower ports, bounded configuration,
cleanup integration and preservation of ordinary lowering. The collection child
owns physical-source/provider/loan/effect/profile authority and the fresh public
source entry. This port is not a public saved-MIR or saved-candidate permission
interface. Complete new-facts HIR persistence remains open.

`bb4f51a557b3ebb084cdff10c8cbbef9b0d2d2c76d7ab13296135aa214440d1d` to
`880d516f75b97808049b9d361ce13ef657a1e83a822b452e22f18f6f5ab36e82`.
The ordinary and constructor-only entry signatures remain; they call the shared

`sh_l_collection_flow_parts` takes text, AST, owned checked/ownership, maximum,

six-word factory rows, nine-word hook rows and explicit roots. Hooks are
`[call, kind, actual SG binding, actual Fn type, T, actual C provider binding,
receipt/operation, program Option type (-1 for push), reserved0]`.
No effect/handle candidate module is imported by the lower.

All mode-specific vector widths/budgets are checked before cloning. A failed
copy cannot silently become empty configuration. Actual source jobs require
explicit roots, checked body state1 and the exact concrete declared Fn type.
Extra source calls fail5008 before discovering executable helper jobs. The flow
supports only i64/bool element types; ordinary constructor-only Owner support
remains separate. The default branch metadata and validation are unchanged.
Flow brif edges retain first-true/second-false identity for strict optional guards.

Canonical role/T cleanup is generated through the independently validated
physical cleanup module. Its real layout is established before body generation;
the concrete destructor is recorded and every cleanup body is revalidated at
module completion. Flow callbacks retain exact layout and both concrete body
validators; the ordinary public callback validator is not relaxed to accept27.
The complete flow module goes through strict optional-physical validation.
Ordinary public lower/native retain their prior candidate27 rejection.

Push transfers actual source temporary responsibility to the physical sink.
Only proved whole-root temporary drop actions are skipped; unknown child paths
reject. Sink disarming is explicit initialization state, never inferred from
zero bytes. Physical consumed/unconsumed status behavior remains separately
owned and qualified. Fresh-source authority, aliases and semantic caller moves
are independently revalidated by the collection entry before this port.
