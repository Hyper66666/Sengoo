# Realworld Support Matrix

This matrix is the user-facing fact source for support and known gaps covered by
the realworld package loop.

**v0.2 stable release evidence SHA:**
`92c8f399f61b73d63990581c637da68572b6e133` ([PR #56](https://github.com/Hyper66666/Sengoo/pull/56)).
The six same-SHA main gates, four-host distribution run `30190137130`, and
`v0.2.0` tag run `30191226253` passed sanitizer, fuzz, compile-scale,
compatibility, installed realworld, package, upgrade, and rollback gates.
Schannel on Windows and rustls on Linux, macOS x64, and macOS arm64 complete
the verified-CA/`localhost` client/server composition without a verification
bypass or plaintext fallback.
