# Realworld Support Matrix

This matrix is the user-facing fact source for support and known gaps covered by
the realworld package loop.

| Capability | Status | Host scope | Proof example/test | Stable diagnostic/status | Upstream spec/change |
| --- | --- | --- | --- | --- | --- |
| Package locked loop (`update`, `check`, `test`, `fmt --check`, `doc`, `build`) | Supported | All hosts with `sgc`, `sgpm`, and `sgfmt` available | `tools/sgpm/tests/integration.rs::realworld_locked_project_loop_keeps_lockfiles_current`; manual fixture commands in `examples/realworld/README.md` | Stale lockfiles require `sgpm update`; locked commands do not rewrite `Sengoo.lock` | `sgc-test-manifest-tooling`, `mainstream-usable-loop` |
| CLI args | Supported | Process argv | `examples/realworld/cli-json-audit/src/main.sg`; `examples/realworld/cli-json-audit/tests/audit_smoke.sg` | Missing optional args use explicit defaults | `stdlib-breadth-mainstream` |
| File and directory IO | Supported subset | Local filesystem | `examples/realworld/cli-json-audit/src/main.sg`; `tools/sgc/tests/realworld.rs::realworld_sources_check_through_sgc_command` | File/dir errors map through `std::status` codes | `stdlib-next-usability-wave` |
| JSON parse/build/status | Supported subset | Runtime JSON helpers | `examples/realworld/cli-json-audit/src/main.sg`; `examples/realworld/http-client-status/src/main.sg`; `tools/sglsp/src/stdlib.rs::realworld_*` fixtures | Parse failures expose `STATUS_PARSE` and last-error helpers | `stdlib-next-usability-wave` |
| Collections helpers | Supported subset | Runtime-backed `Vec<i64>` and map/list handles | `examples/realworld/cli-json-audit/src/main.sg`; `tools/sglsp/src/stdlib.rs::realworld_cli_json_audit_imports_expose_completion_and_signatures` | Invalid handles use status-returning helpers where exposed | `stdlib-breadth-mainstream` |
| Logging | Supported | Runtime test sink and process logs | `examples/realworld/cli-json-audit/src/main.sg`; `examples/realworld/http-client-status/src/main.sg` | Invalid levels map to status results | `stdlib-breadth-mainstream` |
| HTTP over `http://` | Supported subset | Local/plain HTTP hosts | `examples/realworld/http-client-status/src/main.sg` imports `std::http`; runtime-level HTTP tests cover host networking separately | Runtime net errors map to `std::status` | `stdlib-breadth-mainstream` |
| TLS/HTTPS and unsupported HTTP schemes | Platform-specific / unsupported subset | Host network stack; HTTPS is not claimed by this lane | `examples/realworld/http-client-status/src/main.sg` uses `ftp://` unsupported path | `STATUS_UNSUPPORTED` for unsupported schemes | `runtime-hardening-ffi-async`, `stdlib-next-usability-wave` |
| Process command capture | Supported subset | Host process spawning | `examples/realworld/workspace-doc-loop/src/lib.sg`; `tools/sglsp/src/stdlib.rs::realworld_workspace_doc_loop_imports_expose_completion_and_signatures` | Timeouts/statuses are explicit on `ProcessOutput` | `stdlib-next-usability-wave` |
| Background process management | Deferred | N/A | Matrix row, no realworld success claim | Use foreground `ProcessCommand.run`; no background handle API | `stdlib-next-usability-wave` |
| Process cancellation | Deferred | N/A | Matrix row, no realworld success claim | Use command timeout status; no cancellation handle API | `runtime-hardening-ffi-async` |
| Async IO wakeups | Deferred | N/A | Async examples and compiler/runtime tests, not realworld package loop | Unsupported async shapes produce compiler diagnostics where covered | `runtime-hardening-ffi-async` |
| User-defined Future support | Deferred | N/A | Async support tests, not realworld package loop | Unsupported async frame/result shapes produce compiler diagnostics | `runtime-hardening-ffi-async` |
| Multi-operand select | Deferred | N/A | Async examples cover current bounded select shape, not realworld package loop | Unsupported select expansion remains a documented gap | `runtime-hardening-ffi-async` |
| Select loser cancellation | Deferred | N/A | Matrix row, no realworld success claim | No cancellation guarantee is claimed | `runtime-hardening-ffi-async` |
| Timeout behavior | Supported subset | Process and network helpers with timeout args | `examples/realworld/http-client-status/src/main.sg`; stdlib process/network runtime tests cover timeout status paths separately | Timeout status maps to `STATUS_TIMEOUT` where runtime returns it | `runtime-hardening-ffi-async` |
| Task cancellation boundaries | Deferred | N/A | Matrix row, no realworld success claim | No user task cancellation API is claimed | `runtime-hardening-ffi-async` |
| Compression | Deferred | N/A | Matrix row, no realworld success claim | No public `std::compression` package surface | `stdlib-next-usability-wave` |
| Terminal/fd APIs | Deferred | N/A | Matrix row, no realworld success claim | Use current `std::io` helpers only | `stdlib-next-usability-wave` |
| Recursive file transfer | Deferred | N/A | Matrix row, no realworld success claim | Current examples use explicit file/dir helpers | `stdlib-next-usability-wave` |
| Shell pipelines | Deferred | N/A | Matrix row, no realworld success claim | Use explicit `ProcessCommand` arguments | `stdlib-next-usability-wave` |
| Dynamic FFI availability | Platform-specific / deferred | Host dynamic library support | Reflection/FFI examples and runtime hardening tests | Unsupported ABI/dynamic signatures report diagnostics | `runtime-hardening-ffi-async` |
| Owned string return boundaries | Supported subset | Runtime owned-string helpers | Existing stdlib tests; realworld examples use caller-managed buffers instead of claiming broad owned-string returns | Runtime handle/status helpers guard ownership | `stdlib-next-usability-wave` |
| Package/test/doc diagnostics | Supported and expanding | `sgpm`, `sgc`, package manifests | `tools/sgpm/tests/integration.rs::realworld_locked_project_loop_keeps_lockfiles_current`; `build_locked_rejects_stale_lockfile_before_invoking_sgc`; `tools/sgc/src/commands/test.rs::json_report_has_schema_fields` | Stale lock, malformed manifest, and test JSON reports are asserted | `sgc-test-manifest-tooling`, `mainstream-usable-loop` |
| LSP stdlib import coverage | Supported and expanding | Editor reduced fixtures | `tools/sglsp/src/stdlib.rs::realworld_*`; `tools/sglsp/src/diagnostics.rs::realworld_missing_import_json_diagnostic_maps_to_lsp_range`; `tools/sglsp/src/formatting.rs::realworld_cli_json_audit_imports_format_with_keyword_logicals` | `sgc` JSON import diagnostics map to LSP diagnostic ranges and codes | `sgc-test-manifest-tooling`, `mainstream-usable-loop` |
