# Try and Match Ergonomics Examples

Small programs that exercise postfix `?`, `try {}`, and enum `match` patterns.

| File | Topic |
|---|---|
| `01_result_question.sg` | `Result` / `Option` propagation with `?` |
| `02_try_block.sg` | `try { ... }` with explicit outer handling |
| `03_enum_match.sg` | Enum variants, guards, and or-patterns |

Run with:

```bash
sgc run examples/ergonomics/<file>.sg -O 1
```
