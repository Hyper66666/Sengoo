Sengoo Language Tutorial

Sengoo is a self-developed compiled language focused on practical engineering outcomes: hybrid Python migration, fast compile feedback, and LLVM-native output.

This tutorial is written for developers who need to understand what Sengoo is, how to write valid programs, and where this language fits in real projects.

Sengoo 编程语言教程

Sengoo 是一门自研编译型语言，目标聚焦工程落地：支持 Python 渐进迁移、提供快速编译反馈，并通过 LLVM 输出原生程序。

本教程面向开发者，重点回答三件事：这是什么语言、如何写出合法程序、在真实项目中适合用在哪里。

3. What Type of Language Is Sengoo?

DimensionSengoo Today
Execution modelCompiled language with LLVM IR generation and native-link path.
Typing modelStatic type checker with inference for many local bindings and explicit return types in common practice.
Syntax stylePython-like keywords (`def`, `for`, `if`) with brace-delimited blocks.
Tooling modelCLI-first workflow (`sgc`) + VS Code extension.
Performance focusIncremental compile pipeline and native runtime execution path.
Interop strategyRuntime-level Python interoperability for gradual migration scenarios.
Sengoo is not a Python interpreter replacement. It is a compiled systems-oriented language designed to coexist with Python-heavy stacks.

3. Sengoo 属于哪种语言？

维度当前形态
执行模型编译型语言，生成 LLVM IR，并支持原生链接执行。
类型模型静态类型检查；局部绑定可做较多推导，函数返回常显式标注。
语法风格关键词接近 Python（`def`/`for`/`if`），但使用大括号代码块。
工具形态CLI 优先（`sgc`）+ VS Code 插件。
性能方向重点优化增量编译链路与原生执行性能。
互操作策略通过运行时层提供 Python 互操作，支持渐进迁移。
Sengoo 不是 Python 解释器替代品，而是面向工程性能与迁移路径的编译型语言。

4. Core Features

  • Function-oriented syntax: `def name(...) -> type { ... }`.
  • Structured data: arrays, structs, fields, indexing, and method calls.
  • Control flow: `if/else`, `for-in`, `while`, `loop`, `break`, `continue`, `return`.
  • Implementation blocks: attach methods via `impl`.
  • Incremental compiler pipeline: cache metadata, module fingerprints, workset-aware rebuild.
  • Daemon mode: persistent compiler process to avoid repeated startup overhead.
Some grammar forms are present in AST/parser but may still be experimental at full codegen/runtime level. Treat examples under examples/ and active benchmark suites as the currently validated surface.

4. 核心特性

  • 函数中心语法：`def name(...) -> type { ... }`。
  • 结构化数据：数组、结构体、字段访问、索引、方法调用。
  • 控制流：`if/else`、`for-in`、`while`、`loop`、`break`、`continue`、`return`。
  • 实现块：通过 `impl` 为类型挂载方法。
  • 增量编译管线：缓存元数据、模块指纹、workset 感知重编译。
  • Daemon 模式：常驻编译进程，降低重复冷启动成本。
部分语法虽然已进入 AST/Parser，但在完整代码生成或运行时层面仍可能处于实验阶段。建议以 examples/ 和当前基准用例可跑通的能力为准。

5. Syntax Reference (Detailed Learning Version)

This section is the practical syntax handbook for developers who are starting Sengoo from zero.

5.1 Minimal grammar map

program      := decl*
decl         := function | struct | enum | impl | trait | const | static | import | module
function     := "def" ident "(" params? ")" ("->" type)? block
block        := "{" stmt* expr? "}"
stmt         := "let" ... ";" | "const" ... ";" | expr ";" | decl
expr         := literal | ident | call | method_call | if | for | while | loop | match | ...
Compiler internals support more forms than the examples show. For learning, start with the validated forms from examples/.

5.2 Declaration syntax

Function

def add(a: i64, b: i64) -> i64 {
    a + b
}

Struct

struct Point {
    x: i64,
    y: i64,
}

Impl and methods

impl i64 {
    def abs(self) -> i64 {
        if self < 0 { -self } else { self }

Const / Static

Import (parser-level forms)

  • Prefer simple control flow before introducing advanced expression nesting.

7. Python Interoperability

Sengoo currently provides Python interoperability through runtime-level integration (PyO3 path), used by benchmark suites and hybrid deployment workflows.

What this enables

  • Keep Python orchestration while moving hot loops/modules to compiled native paths.
  • Measure cross-boundary costs using the dedicated interop benchmark suite.
  • Adopt gradual migration instead of hard rewrites.

8. Performance Model

  • Runtime track: native execution aims to stay in the same performance class as C++/Rust for loop-heavy scenarios.
  • Compile track: emphasis on incremental reuse through fingerprints and workset planning.
  • Link track: link time is measured explicitly in advanced pipeline suite.
Use benchmark reports in the independent bench repository to evaluate regressions and compare trend lines over time.

8. 性能模型

  • 运行时维度：原生执行目标是在循环密集场景接近 C++/Rust 量级。
  • 编译维度：通过指纹和 workset 计划强化增量复用。
  • 链接维度：在 advanced pipeline 中单独统计链接阶段。
建议使用独立的 bench 仓库持续跟踪性能趋势和回归。

9. Application Scenarios

  • Compute-heavy modules in Python services.
  • CLI and automation tools requiring short edit-run loops.
  • Algorithmic components distributed as native binaries.
  • Compiler/language experiments with measurable performance gates.

9. 应用场景

  • Python 服务中的计算密集型模块加速。
  • 需要快速迭代反馈的 CLI 与自动化工具。
  • 以原生二进制交付的算法组件。
  • 具备可观测性能门禁的编译器/语言实验项目。

10. Current Status and Expectations

Sengoo is in early but fast-iterating stage. Compiler and runtime are usable, while some language areas are still under active optimization and stabilization.

  • Validated: core syntax from examples, incremental pipeline, benchmark suites, Python interop benchmarks.
  • Evolving: broader frontend architecture, reflection ergonomics, and larger-scale optimization.

10. 当前状态与预期

Sengoo 目前处于早期但快速迭代阶段。编译器与运行时已可用，但部分语言能力仍在持续优化和稳定化中。

  • 已验证：示例覆盖的核心语法、增量编译链路、基准套件、Python 互操作基准。
  • 持续演进：前端架构、反射能力工程化、规模化性能优化。

11. FAQ

Why braces if keywords look Python-like?

Sengoo intentionally combines readable control keywords with explicit block boundaries for compiler and tooling clarity.

Does Sengoo replace Python?

Not as a full replacement. The practical strategy is coexistence: Python for orchestration, Sengoo/native for hot paths.

Where should I continue after this tutorial?

Read docs/DEVELOPMENT_GUIDE.md if you want to contribute to the compiler/runtime/tooling stack.

11. 常见问题

为什么关键词像 Python，但代码块用大括号？

这是有意设计：保留可读性，同时使用明确边界提升编译器与工具链处理稳定性。

Sengoo 是要完全替代 Python 吗？

不是。更实用的路径是共存：Python 负责编排，Sengoo/原生模块负责热点计算。
