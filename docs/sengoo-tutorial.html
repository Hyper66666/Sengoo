Sengoo Language Tutorial (Detailed Edition)

Sengoo is a self-developed compiled language focused on practical engineering outcomes: fast edit-build-run loops, LLVM-native execution, and smooth migration for Python hotspots.

This page is intentionally detailed, like a reference site. Each chapter includes syntax, runnable examples, operational advice, and common pitfalls.

Sengoo 语言教程（详细版）

Sengoo 是一门自研的编译型语言，面向工程落地：快速编辑-编译-运行反馈、LLVM 原生执行、以及 Python 热点模块平滑迁移。

本页按参考手册方式组织，每章提供语法说明、可运行示例、工程建议和常见问题。

4. Syntax Basics

// comment
def main() -> i64 {
    42
}
  • Use braces for all blocks.
  • Use semicolons on local declarations/assignments.
  • Leave off semicolon on final expression when returning.

4. 语法基础

// 注释
def main() -> i64 {
    42
}
  • 所有代码块统一使用花括号。
  • 局部声明与赋值语句建议使用分号。
  • 块末尾返回表达式通常不加分号。

19. Common Errors and Fixes

  • command 'sengoo.run' not found: reinstall extension and run Developer: Reload Window.
  • invalid pattern: expected field name: check struct/pattern field syntax and use sgc dump-ast.
  • Noisy compile errors: run sgc check first, then --force-rebuild.

19. 常见错误与排查

  • command 'sengoo.run' not found：重装插件后执行 Developer: Reload Window。
  • invalid pattern: expected field name：检查结构体/模式字段语法，并用 sgc dump-ast 定位。
  • 报错不清晰：先跑 sgc check，再尝试 --force-rebuild。

22. FAQ

Is Sengoo a Python replacement?

Usually no. Practical architecture is coexistence: Python orchestration + Sengoo/native hotspots.

Does auto reflection add overhead to all projects?

No. In --reflect=auto, reflection activates only when reflect import is detected.

22. 常见问题

Sengoo 是要替代 Python 吗？

通常不是。更实用的是共存架构：Python 编排 + Sengoo/原生热点模块。

自动反射会拖慢所有项目吗？

不会。在 --reflect=auto 模式下，只有检测到反射导入才启用。
